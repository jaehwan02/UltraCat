UltraCat 1.0.49

- Prevents UltraCat from appearing to freeze on some M4 Pro Macs when applying fan settings.
- Stops probing unrelated SMC fan target data types after a cached target format is rejected.
- Keeps the safer target RPM behavior from the previous release while avoiding wrong-size SMC fan writes.
