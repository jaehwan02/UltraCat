UltraCat 1.0.70

- Adds a Token Usage tab with a GitHub-style daily heatmap. Hover a day to see its tokens, cost, and usage per model, and page back to the first recorded day.
- Shows all-time token usage and cost by model, combining the same model used through different providers.
- Updates the bundled ccusage scanner to 20.0.24. Saved usage history now accepts corrected totals from the scanner when a later scan lowers a day's count.
