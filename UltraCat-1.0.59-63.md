UltraCat 1.0.59

- Adds an option to keep the Mac awake with the lid closed only while plugged in.
- Lets battery mode return to normal macOS lid sleep when plugged-in-only wake is enabled.
- Rechecks and reapplies lid sleep behavior when power source changes or the app starts.
